# Work Mac (PC-M-2025-026)

## Review: tier 2 fallback

When Codex cannot run (an outage, a rate limit, an expired login), run the same review with GitHub Copilot CLI before falling back to tier 3. It is the same model, GPT-6.1 Sol, so use it only in place of Codex, never as a second opinion on a Codex review. Tell the user you switched.

Do not pass `--allow-all-tools` or `--allow-all-paths`, so it cannot edit. Copilot reads only under its working directory; when the file is elsewhere (the scratchpad, a Gist clone), pass that file's directory with `--add-dir`, on the re-review too:

```bash
copilot -p "Review this plan. Don't nitpick trivial points; only point out fatal issues: {full_path}" --model gpt-6.1-sol --reasoning-effort medium --add-dir {dir_of_full_path}

# re-review: the end of the first run prints "Resume copilot --resume=..."
copilot --resume={session_id} -p "I updated it; review it again. Don't nitpick trivial points; only point out fatal issues: {full_path}" --model gpt-6.1-sol --reasoning-effort medium --add-dir {dir_of_full_path}
```

Re-review with the tool that did the first review, even if Codex works again.
